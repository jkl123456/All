# 知屿 · 游戏设计文档

> 文档版本：v2.0「手作光」  
> 对应实现：`knowledge-archipelago`  
> 关键词：知识群岛、模拟经营、3D 建造、跨学科学习、程序化美术

---

## 1. 设计目标

### 1.1 核心问题

很多“学习游戏”把知识做成一道门：答对才能继续，答错就重来。知识因此停留在界面里，没有进入玩家真正关心的东西。

《知屿》希望把知识做成**材料、工具和土地**：

- 数学不是一个分数，而是你能造出的第一座桥。
- 化学不是一条方程式，而是能承受更高炉温的合金。
- 生物不是一张细胞图，而是暖房里提前成熟的那一株月莓。
- 语文不是一段默写，而是一把会让木屑排成诗句的斧。

### 1.2 三条设计支柱

1. **知识必须落地**：每一个学科岛屿的主试炼都对应至少一种建造、锻造、种植或居民系统。
2. **岛屿必须生长**：玩家看得见土地变大、建筑变多、灯变亮、居民愿意留下。
3. **学习必须安全**：答错不毁岛，只把答案收进知海；可以重试，可以在任何时间停下来生活。

### 1.3 目标体验

- 前 10 分钟：玩家知道去哪里、怎么砍第一棵树、怎么建第一间工坊。
- 前 30 分钟：玩家修好码头、抵达第一座知识岛、通过一次试炼、带回第一件信物，并发现奖励能改变家岛。
- 2–4 小时：完成七座知识岛的主线、扩建岛屿、迎来居民、建起灯塔与观星台。
- 长期：继续自由建造、收集 112 张知识卡、在不同难度下重访七座岛。

## 2. 玩家旅程

### 2.1 “第一根梁木”时刻

开始状态：

- 一座旧帐篷、三块田、一个守岛人、一座断码头；
- 8 木材、5 石料、5 纤维、3 食物、90 银叶币；
- 精力 100；
- 第一根主线目标：造一座木作工坊。

玩家需要走到最近的可采集树、采集木材、打开蓝图、看清“绿色可以放 / 红色不可以放”的反馈、放下第一座建筑。完成后自动得到任务奖励并解锁码头修复目标。

### 2.2 岛屿生长阶段

| 阶段 | 玩家拥有的东西 | 情感目标 |
|---|---|---|
| 落地 | 帐篷、农地、工坊 | “这里可以住。” |
| 开放 | 修好的码头、海图、第一枚信物 | “世界比岛大。” |
| 建设 | 锻炉、暖房、市集、第一座外岛 | “我的选择改变了这里。” |
| 人气 | 旅人小屋、居民、每日委托 | “岛开始属于我们。” |
| 灯火 | 灯塔、七枚信物、观星台 | “问题也能成为归处。” |

### 2.3 关键节奏

- **第一个奖励**：工坊完成后立即给银叶币、悟性与种子，不设领取门槛。
- **第一次远航**：修好码头后所有知识岛开放，玩家自由选择顺序，避免把探索锁成线性章节。
- **第一次扩建**：通过数学试炼、造桥后解锁东屿；扩建是真正的新地形和新的建造区域。
- **第一次居民**：生物主试炼 + 旅人小屋；阿禾会带着礼物与生活句子住到岛上。
- **终局**：集齐七枚信物，建造星辉观星台，以一段可继续游玩的终章收束。

## 3. 循环结构

### 3.1 分钟级循环

采集 → 获得材料 → 查看蓝图 / 配方 → 放置或锻造 → 获得反馈（视觉、音效、浮动粒子、Toast、手记进度）→ 继续。

### 3.2 小时级循环

出海 → 探索岛屿地标 → 和守岛人对话 → 完成试炼 → 收集知识卡与信物 → 回岛 → 用信物解锁更高级系统 → 扩建 / 招居民 → 接受新的主线目标。

### 3.3 长期循环

岛屿更繁荣 → 有人住下 → 每日委托和礼物形成回到岛上的理由 → 在四档难度中重访、刷更高品质造物 → 完成知海收集。

## 4. 系统设计

### 4.1 学科岛屿矩阵

每座知识岛有：

- 独立的地形与调色板；
- 2–3 个程序化地标（如机关齿轮、元素池、巨型蘑菇、灯塔）；
- 1 位守岛人：世界观对话 + 当前主线提示；
- 2 处试炼：主试炼（信物 + 印记）与支线试炼（资源 + 知识卡）；通过主试炼后，守岛人会在后续对话里送出一次性的临别小道具；
- 4–5 个本地采集点；
- 本地资源产出，与家岛的建造 / 锻造配方形成往来。

| 学科 | 主试炼奖励 | 解锁 / 改变的系统 |
|---|---|---|
| 语文 | 文心墨玉 | 文心斧、文心长剑 |
| 数学 | 定理齿轮 | 月拱桥、星泉 |
| 物理 | 机巧晶核 | 晶脉镐、以太战锤 |
| 化学 | 元素精华 | 元素合金斧 |
| 生物 | 生命之种 | 暖房、月莓、星莲、阿禾入住条件 |
| 英语 | 星海航图 | 守望灯塔 |
| 百工 | 百工徽章 | 潮汐市集、居民陆叙 |

### 4.2 难度与品质

难度由玩家选择的“学者段位”确定，而不是游戏内随时切换。四个段位映射四套题池：

- 白银（初中）
- 黄金（高中）
- 钻石（大学）
- 王者（研究生）

实现上：

- `RANKS[id].level` 决定 `drawQuestions()` 从哪一个题池抽取；
- `RANKS[id].tier` 影响：
  - 新建筑的装饰与材质（木石 → 鎏金 → 晶辉 → 星王）；
  - 工具评级与炉火祝福；
  - 银币、悟性与部分资源的倍率。
- 难度不锁故事、不降低主线可行性；它只会改写问题的深浅与回报的华丽程度。

### 4.3 建造系统

- 自由网格放置，但限定在岛屿 / 扩建台地的可建区域内；
- 以圆形绘制“建造范围”，实时校验与已有物体、建筑、农田、树木的距离；
- 绿色 / 红色幽灵预览；
- 建筑按段位生成不同 tier 的视觉；
- 建筑注册为场景交互点，也注册为建造占用物；
- 外岛扩建会重建地形与行走 / 建造区域，并生成可通行的连接桥；
- 建筑被记录到状态里，换岛或刷新后重建。

### 4.4 锻造系统

- 配方由材料、前置试炼、玩家段位共同决定；
- 三锤小游戏衡量时机，计算平均火候评分；
- 品质：粗制、良作、精工、传世；
- 工具保留：名称前缀、品质、能力加成、锻造日期、是否已装备；
- 自动装备更强的同类工具；
- 产出工具用途：木材/石料采集效率、精力上限。

### 4.5 时间、精力、天气

- 时间以现实时间缓慢推进；使用主界面、对话、答题、锻造、建造等面板时暂停；
- 23:30 提醒，24:00 后时间冻结在深夜，等待玩家回帐篷；
- 睡眠：推进一天、恢复精力、刷新每日任务、重建采集节点、让作物成长、结算市集和磨坊；
- 天气按日种子从四种天气中抽取，服务于晨间总结和氛围；
- 精力花费：采集 4、种植 2、收获 1、锻造 4、建造 2；食物恢复 20；
- 精力不为惩罚：为 0 时仍可探索、旅行、答题；只是暂时不能进行消耗行动。

### 4.6 居民

- 6 位居民，每人有：头衔、3D 外观、一段入住介绍、3 句日常对话、每日礼物、符合自己气质的条件；
- 条件通常是某学科主试炼 + 旅人小屋；
- 居民会在家岛散步，靠近时面向玩家；
- 居民被记录存储在存档中，回岛和刷新后重建；
- 当前容量 = 旅人小屋数量；
- 新居民加入后刷新家岛，让 NPC 真实出现。

### 4.7 每日委托

- 三类筛选来源：采集、答题、收获、建造、旅行、交谈、锻造；
- 每天随机 3 件，即使已经完成也会在面板中显示；
- 完成后自动发奖，不需要跑回 NPC；
- 新手期会避开未开放内容（如码头未修好时不会出旅行/答题）。

### 4.8 主线

16 章主线，围绕“把知识带回家”展开，目标是让玩家逐步触达每个系统：

1. 工坊 → 2. 码头 → 3. 语文 → 4. 数学 → 5. 桥 → 6. 扩建 → 7. 生物 → 8. 收获 → 9. 物理 → 10. 锻造 → 11. 化学 → 12. 英语 → 13. 百工 → 14. 市集 → 15. 灯塔 → 16. 观星台。

任务目标类型包括绝对条件（建筑、试炼、码头、扩建）与事件计数（收获、锻造）。任务完成后：

- 自动发放奖励；
- 自动推进到下一章；
- 若下一章的前置条件已经在此前的自由探索中满足，自动检查并继续；
- 弹出手记式“主线完成”界面（若当前有对话/答题界面则排队）。

## 5. 学习设计

### 5.1 题目

- 总题库 112 道；
- 结构：7 学科 × 4 难度 × 4 题；
- 每题包含：题干、四项选择、正确答案、讲解、主题标签；
- 试炼抽取同岛同难度池中的 3 道；通过线 2/3；
- 抽题随机，重复挑战可遇到不同组合；
- 答错仍把题目与讲解收进知海，因此“失败”也保留学习成果。

### 5.2 难度覆盖示例

- 语文：成语、诗词、病句 → 文学史、索绪尔、训诂、反切
- 数学：一元一次方程、概率、圆面积 → 行列式、定积分、群论、正交矩阵
- 物理：速度、串联电路 → 角动量、LC 振荡、麦克斯韦位移电流、诺特定理
- 化学：pH、物态变化 → 吉布斯自由能、SN1、米氏常数、对映异构
- 生物：叶绿体、气孔 → 中心法则、NPP、DNA 甲基化、CRISPR
- 英语：时态、词义 → 语用学、互文性、学术模糊限制语、逻辑谬误
- 百工：急救、用电安全 → NPV、关键路径、中心极限定理、沉没成本

### 5.3 反馈

- 选择后立即标出对错与正确答案；
- 解释区使用“知识卡”语气，避免训斥；
- 结果页汇总三道题的主题、对错；
- 首次通过给出学科信物与本地物产；重复通过给少量资源与悟性；
- 难度越高，信物奖励的悟性和资源倍率越高。

### 5.4 知识回流

每次答题将题目 ID 记录进知海。知海支持：

- 按学科筛选；
- 全文搜索；
- 展开查看正确答案与讲解；
- 显示收集数量与试炼统计。

## 6. 视觉与听觉方向

### 6.1 视觉

- 低多边形、手工缩微景观、柔和雾色、植物与海水的慢节奏；
- 海岸植被与码头接入热带环境包（Tropical Rain Forest Environment Pack v2.0）：棕榈、香蕉、号角树、蕨类、象耳芋、海滩草、海蚀岩与木栈桥使用其 DAE/DDS 转换来的 GLB；号角树与棕榈用 `alphaTest` 叶片和双面材质，木栈桥由三段真实栈桥拼成，破损状态会留出可修复的缺口；
- 岛屿有自己的调色板和地标：墨竹与砚池、几何浮体、齿轮与摆锤、玻璃瓶与发光池、巨菇与蝴蝶、灯塔与白帆、市集与脚手架；
- 建筑分四档品质：木材/石材 → 鎏金/旗帜 → 晶石/玻璃 → 黑曜石/金纹；
- UI 使用羊皮纸、手记、海图、印章的视觉隐喻，而不是科幻面板；
- 全屏覆盖、卡片、海图和答题界面都使用不同的布局节奏，避免所有内容长得一样。

### 6.2 声音

- Web Audio 实时合成：低频潮汐、和声垫、远风铃；
- 采集、获得资源、解锁、锤击、锻造成功、读题正确/错误、码头落成、睡眠、旅行；
- 无外部音频文件；在用户首次交互后解锁；
- 声音开关状态会存入设置与存档。

### 6.3 可读性与响应式

- 重要信息使用至少约 12px 的视觉字号（以 1440 桌面截图验收）；
- 高密度面板使用分组、留白与颜色对比；
- 移动端：隐藏小地图、把精力移到摇杆上方、自动收起建造面板、只保留必要的触屏控件；
- 移动端自动横屏：入口层用固定横向视口承载游戏，竖屏时外层旋转铺满，横屏时自然正立；不放“请旋转手机”的遮罩，让媒体查询、触摸坐标与相机都保持横屏语义；
- 键盘焦点样式与减少动效媒体查询已包含。

## 7. 技术设计

### 7.1 数据驱动

- `gameData.js`：岛屿、段位、资源、信物、建筑、工具、作物、居民、扩建与委托池；
- `questions.js`：112 道题；
- `quests.js`：16 章主线；
- `GameState` 只序列化纯数据，Three.js 场景根据数据重建。

### 7.2 场景生成

- 岛屿地形：自定义 BufferGeometry，多重环带 + 不规则海岸 + 崖壁 + 水下基座；
- 水面：自定义顶点位移与片元着色器，包含菲涅尔、日光高光、波光、雾化与昼夜颜色；
- 天空：渐变穹顶、日/月方向、星野、云与远岛剪影；
- 建筑：每种建筑由基础体、屋顶、功能部件、段位装饰组合生成；
- 热带植被：`public/models/tropical/` 中的 GLB 由 Torque 3D 资源离线转换，运行期通过 `GLTFLoader` 预加载并克隆；克隆共享几何、材质与贴图，避免每座岛重复占用显存；
- 标记：程序化 Canvas 纹理精灵，重要交互有“问 / 答 / 谈 / 船 / 田 / 信 / 知”等符号；可采集物只有微弱呼吸光，避免标签污染。

### 7.3 性能取舍

- 像素比上限 1.75；低画质关闭阴影；
- 阴影贴图 2048（高）/1024（中）；
- 树木、岩石、花草、建筑共享材质缓存；
- 标签纹理与文字牌在离开岛屿时主动释放；
- 粒子使用独立 Points，生命周期结束后释放几何体和材质；
- 交互标记会跟随 NPC，但数量有限；
- 如果 WebGL 不可用，页面显示可重试的降级错误页。

### 7.4 存档与兼容

- 单存档键，自动保存；
- 读取时做字段归一化、数值钳制、无效建筑 / 信物过滤；
- 存档包含版本号、段位、时间、坐标、资源、建筑、扩建、试炼、印记、图鉴、装备、作物、居民、每日任务、统计与设置；
- 刷新后标题页显示继续按钮与概要。

## 8. 已知边界

- 单人、本地单存档；没有云同步或账号。
- 没有战斗系统；武器用于精力加成，是生活与锻造成长的一部分。
- 种植只有三块固定田垄与三种作物；未来可以加入更多田块与加工链。
- 题目为通识与课程混合，不等同于完整教材覆盖。
- 没有 NPC 语音；对话与提示以文本、程序化音效与肖像呈现。
- 移动端采用虚拟摇杆与触屏点击，暂未提供双指缩放手势。
- 热带海岸模型来自项目所有者提供的 Tropical Rain Forest Environment Pack v2.0；这些 GLB 的运行与再分发受原包授权约束，详见 [模型来源说明](../public/models/tropical/README.md)。
